# 05 · 示例组件库

> 11 个**可直接导入**的模板，覆盖 svg 轨全部技巧 + builtin 轨预设变体。
> 每个示例都在 `examples/` 下有同名 `.widget.json` 文件（用管理页「导入」即可）。
> 文中给出 SVG 源码、默认属性、schema 要点，以及它演示的占位符/技巧。
>
> 生成这些文件的脚本在 `gen_examples.py`（改完重跑即可重新导出）。

---

## 怎么用这些示例

1. 打开 **组件模板管理**页 → **导入** → 选 `examples/A-my-tank-level.widget.json`。
2. 冲突策略选 `skip`（已存在就跳过）或 `rename`（想保留自己的版本）。
3. 导入后去任意组态画面，组件库里出现「竖式液位罐」，拖到画布绑定变量即可。
4. 想看源码：管理页点开该模板，**SVG 模板源码 / 默认属性 JSON / 属性 Schema JSON** 三个框就是文件里的内容。

> 所有 svg 轨示例都**自带 `propSchemaJson`**（键与 `defaultPropsJson` 一一对齐）；
> 两个 builtin 轨示例（`H`/`I`）的 `propSchemaJson` 留空 `[]`，**自动复用内置 SFC 的面板**。

## A. my-tank-level · 竖式液位罐　`[svg]`

**演示**：技巧 1（嵌套 `<svg>` + 百分比）、`{normalizedPercent}`、`{activeColor}`、`{value}{unit}`、`{label}`。

```xml
<svg width="100%" height="100%" viewBox="0 0 120 170" xmlns="http://www.w3.org/2000/svg">
  <text x="60" y="14" font-size="10" text-anchor="middle" fill="#94a3b8">{label}</text>
  <rect x="10" y="22" width="100" height="130" rx="10" fill="#0f172a" stroke="{inactiveColor}" stroke-width="3"/>
  <svg x="20" y="32" width="80" height="110" viewBox="0 0 80 110" preserveAspectRatio="none">
    <g transform="translate(0,110) scale(1,-1)">
      <rect x="0" y="0" width="80" height="{normalizedPercent}%" fill="{activeColor}"/>
    </g>
  </svg>
  <text x="60" y="164" font-size="{fontSize}" text-anchor="middle" fill="#e2e8f0">{value}{unit}</text>
</svg>
```

默认属性：`activeColor #3b82f6` / `inactiveColor #94a3b8` / `minValue 0` / `maxValue 100` / `unit %` / 阈值 10·90。

## B. my-pipe-flow-h · 流向管道　`[svg]`

**演示**：技巧 2（`stroke-dasharray`） + `<animate>` 流动虚线（清洗白名单放行 `<animate>`）。

```xml
<svg width="100%" height="100%" viewBox="0 0 200 40" xmlns="http://www.w3.org/2000/svg">
  <rect x="0" y="14" width="200" height="12" rx="6" fill="#1e293b" stroke="{inactiveColor}" stroke-width="2"/>
  <line x1="10" y1="20" x2="190" y2="20" stroke="{activeColor}" stroke-width="6" stroke-linecap="round" stroke-dasharray="14 12">
    <animate attributeName="stroke-dashoffset" from="0" to="-26" dur="0.8s" repeatCount="indefinite"/>
  </line>
</svg>
```

`{activeColor}` 是运行色（运行时 = 设备连通色），停用时取 `inactiveColor`。

## C. my-radial-gauge · 环形进度仪表　`[svg]`

**演示**：技巧 2（`pathLength="100"` + `stroke-dasharray="{normalizedPercent} 100"`）、`{alertColor}` 随阈值变色、`rotate(-90)` 起点置顶。

```xml
<svg width="100%" height="100%" viewBox="0 0 120 120" xmlns="http://www.w3.org/2000/svg">
  <circle cx="60" cy="60" r="48" fill="none" stroke="#1e293b" stroke-width="12"/>
  <circle cx="60" cy="60" r="48" fill="none" stroke="{alertColor}" stroke-width="12"
          pathLength="100" stroke-dasharray="{normalizedPercent} 100"
          transform="rotate(-90 60 60)" stroke-linecap="round"/>
  <text x="60" y="58" font-size="{fontSize}" text-anchor="middle" fill="#e2e8f0">{value}{unit}</text>
  <text x="60" y="74" font-size="9" text-anchor="middle" fill="#94a3b8">{label}</text>
</svg>
```

⚠ `stroke-linecap="round"` 时 `pct=0` 会画成一个小圆点；在意的话改成 `butt`。

## D. my-linear-bar · 水平进度条　`[svg]`

**演示**：嵌套 `<svg>` 让宽度百分比相对「进度槽」而非整个画布（同技巧 1，用在 X 方向）。

```xml
<svg width="100%" height="100%" viewBox="0 0 200 36" xmlns="http://www.w3.org/2000/svg">
  <rect x="4" y="10" width="192" height="16" rx="8" fill="#1e293b" stroke="{inactiveColor}" stroke-width="1.5"/>
  <svg x="4" y="10" width="192" height="16" viewBox="0 0 192 16" preserveAspectRatio="none">
    <rect x="0" y="0" width="{normalizedPercent}%" height="16" rx="8" fill="{alertColor}"/>
  </svg>
  <text x="100" y="32" font-size="9" text-anchor="middle" fill="#94a3b8">{label}</text>
</svg>
```

用 `{alertColor}` 而非 `{activeColor}`，让进度条**超阈值自动变红/黄**。

## E. my-status-lamp · 状态指示灯　`[svg]`

**演示**：技巧 5/6（`{alertColor}` 状态色 + `{quality}` 条件显示）、`{state}` 文案。

```xml
<svg width="100%" height="100%" viewBox="0 0 80 40" xmlns="http://www.w3.org/2000/svg">
  <circle cx="18" cy="20" r="12" fill="{alertColor}">
    <animate attributeName="opacity" values="1;0.4;1" dur="1.2s" repeatCount="indefinite"/>
  </circle>
  <text x="38" y="25" font-size="{fontSize}" fill="#e2e8f0">{state}</text>
  <text x="38" y="14" font-size="9" fill="#94a3b8">{label}</text>
  <text x="72" y="14" font-size="9" fill="#ef4444">{quality}</text>
</svg>
```

- 布尔量开 → `activeColor`（绿）闪烁；关 → `inactiveColor`（灰）。
- 通信异常时右上角出现红色 `Bad`/`CommunicationError`，正常时该文本不存在。

## F. my-thermometer · 温度计　`[svg]`

**演示**：技巧 4（嵌套 `scale` 做 0~100 → 0~H 单位换算）、`{alertColor}` 液柱变色。

```xml
<svg width="100%" height="100%" viewBox="0 0 60 160" xmlns="http://www.w3.org/2000/svg">
  <rect x="24" y="20" width="12" height="110" rx="6" fill="#1e293b" stroke="{inactiveColor}" stroke-width="2"/>
  <circle cx="30" cy="140" r="14" fill="{alertColor}" stroke="{inactiveColor}" stroke-width="2"/>
  <g transform="translate(0,130) scale(1,0.011) scale(1,{normalizedPercent})">
    <rect x="26" y="-100" width="8" height="100" rx="4" fill="{alertColor}"/>
  </g>
  <text x="30" y="14" font-size="{fontSize}" text-anchor="middle" fill="#e2e8f0">{value}{unit}</text>
</svg>
```

系数推导：`H=110` → `scale(1, 110/10000)=0.011`；`pct=100` 时柱高 `100×0.011×100=110`，正好填满。
⚠ 该技巧会拉扁圆角/描边，所以这里只在液柱用、外壳用普通矩形。

## K. my-warning-bar · 预警条　`[svg]`

**演示**：`{alertColor}` 同时驱动边框与文本（技巧 6 叠加），正常时无告警色侵入。

```xml
<svg width="100%" height="100%" viewBox="0 0 220 30" xmlns="http://www.w3.org/2000/svg">
  <rect x="4" y="6" width="212" height="18" rx="4" fill="#0f172a" stroke="{alertColor}" stroke-width="2"/>
  <polygon points="14,10 22,22 6,22" fill="{alertColor}"/>
  <text x="30" y="19" font-size="11" fill="{alertColor}">{label}</text>
</svg>
```

把 `label` 设成告警文案，超阈值时整条边框+三角+文字一起变红/黄。

## H. my-tank-preset · 清水储罐（builtin 预设变体）　`[builtin]`

**演示**：不写 SVG，直接复用内置 `tank` SFC，只改**默认参数**就得到一个新图元。

| 字段 | 值 |
|---|---|
| `RenderType` | `tank`（= 内置渲染器键） |
| `RenderKind` | `builtin` |
| `SvgTemplate` | `null` |
| `defaultPropsJson` | `activeColor #0ea5e9` / `fillColor #38bdf8` / `minValue 0` / `maxValue 50` / `unit m³` / `thresholdMax 45` / `thresholdMin 5` / `showLabel true` |
| `propSchemaJson` | `[]` → **自动复用 `BUILTIN_SCHEMAS['tank']` 面板** |

落布即是一个量程 0~50 m³、超 45 报警的蓝色储罐，连属性面板都不用自己写。

---

## I. my-gauge-temp · 温度表盘（builtin 预设变体）　`[builtin]`

**演示**：复用 `gauge-dial` SFC，量程拉到 `-20~150℃`，超 120℃ 红区报警。

| 字段 | 值 |
|---|---|
| `RenderType` | `gauge-dial` |
| `RenderKind` | `builtin` |
| `defaultPropsJson` | `activeColor #ef4444` / `minValue -20` / `maxValue 150` / `unit ℃` / `thresholdMax 120` / `thresholdMin -10` |
| `propSchemaJson` | `[]` |

> 注意：两个预设变体的 `TemplateKey`（`my-tank-preset` / `my-gauge-temp`）**不等于** `RenderType`，
> 这是 builtin 轨允许的（走 `builtinRenderers` 匹配）。而 svg 轨则强制 `RenderType == TemplateKey`。
