# 06 · 排障与最佳实践

> 把前面 5 篇里最容易出事的结论汇总成「清单 + 坑表」，并给出性能/安全边界。
> 所有条目都可在源码处复现（见 01 §7 源码位置表）。

---

## 一、上线前校验清单（逐条打勾）

### 通用
- [ ] `TemplateKey` 全局唯一、仅含字母数字连字符、≤64
- [ ] svg 轨：`RenderType` **严格等于** `TemplateKey`
- [ ] builtin 轨：`RenderType` 在 `builtinRenderers` 23 个键内
- [ ] `Category` 是 `equipment`/`sensors`/`structures`/`headers` 之一
- [ ] `DefaultPropsJson` / `PropSchemaJson` 都通过「校验」（合法 JSON）

### SVG 轨专属
- [ ] 阈值 `thresholdMin`/`thresholdMax` 在 `defaultPropsJson` 里给了**数字**（不是 `null`）
- [ ] 没在 SVG 里引用不存在的占位符（`{minValue}`/`{maxValue}`/`{qualityBad}`… 都会原样残留）
- [ ] 没写任何表达式（`{100 - x}`/`{x * 1.2}` 不替换）
- [ ] 颜色用 `#rrggbb`（取色器只认 hex）
- [ ] `opacity` 没直接接 `{normalizedPercent}`（0~100 会被当 0~1）
- [ ] 若用 `id`（渐变/滤镜），已规避多实例冲突（见 §三-2）

### 属性面板
- [ ] `propSchemaJson` 里每个 `key` 与 `defaultPropsJson` 的键**完全一致**（大小写敏感）
- [ ] 阈值的 number 控件都加了 `"nullable": true`
- [ ] svg 轨**没**留空 `[]` 指望面板自动出现（自定义 key 不在 `BUILTIN_SCHEMAS`，会空白）
- [ ] builtin 轨若要复用内置面板，留 `[]` 即可（无需手写）

## 二、20 个高频坑

| # | 现象 | 根因 | 解决 |
|---|---|---|---|
| 1 | 画布上整块组件显示「组件缺失: xxx」 | `RenderType` 既不在模板也不在 builtin | 检查 RenderType 拼写 / 重新导入同键模板 |
| 2 | svg 模板保存报「RenderType必须=TemplateKey」 | svg 轨硬约束（前后端双校验） | 把两者改成同一个值 |
| 3 | 画面上一堆 `{thresholdMax}` 字样 | 阈值 `null` 时占位符残留字面量 | defaultProps 里给数字阈值 |
| 4 | 组件属性面板空白 | svg 轨自定义 key 不在 BUILTIN_SCHEMAS，`[]` 回退为空 | 手写 propSchemaJson |
| 5 | 改了模板默认值，老组件没变 | 快照语义：已有键走组件自身值 | 手工改组件，或加新键 |
| 6 | 改了 SVG 源码，所有实例立刻变（含改坏） | SVG 不快照，实时生效 | 先在管理页「实时预览」确认 |
| 7 | 预览里「质量：Good」，上线变「质量：」 | `{quality}` 正常时输出空串 | 以空串为常态设计 |
| 8 | 预览红色，上线变绿 | 预览 `{alertColor}` 固定 `#ef4444` | 理解 alertColor 由阈值动态决定 |
| 9 | `{font-size}` / `{ value }` 原样输出 | 占位符 key 只认 `[a-zA-Z0-9_]` | 去掉连字符和空格 |
| 10 | 写 `{100 - normalizedPercent}` 没替换 | 不支持表达式 | 用嵌套svg/scale/transform 技巧 |
| 11 | 两个同模板实例颜色串台 | 用了重复 `id` 的渐变/滤镜 | 不用 id，或用极特殊命名 |
| 12 | 阈值清不掉，始终报警 | number 控件非 nullable，清空写 `0` | schema 加 `"nullable": true` |
| 13 | 取色器显示错色 | 颜色写了 `red`/`rgb()` | 改 `#rrggbb` |
| 14 | `{qualityBad}` 原样出现 | 该键不在占位符上下文 | 用 `{quality}`（空串=正常） |
| 15 | 开关量显示 `"true"`/`"false"` | 用了 `{value}` 而非 `{state}` | 改 `{state}` 或 `{activeColor}` |
| 16 | 数值一长串无小数位 | `{value}` 原样输出不格式化 | 用内置 `var-display` 的 `decimals`，或设备侧缩放 |
| 17 | 进度条透明度过头 | `opacity="{normalizedPercent}"` 0~100 当 0~1 | 用 §二-4 单位换算映射到 0~1 |
| 18 | 导入后变系统内置 | 伪造 isSystem | 文件 isSystem 一律不信，强制 false |
| 19 | 覆盖导入把内置模板改了 | overwrite 保留库内 IsSystem | 这是预期行为；改内置请走 rename |
| 20 | 存量 `title-header` 组件突然换了样式 | 新 builtin 模板 SortOrder 更小抢了匹配 | 新变体 SortOrder 设大（≥300） |

## 三、性能与安全边界

### 1. 性能

每次绑定值变化，svg 轨 `computed` 重跑：`sanitizeSvg` → `bindSvgTemplate` → `v-html` 重解析整棵子树。

| 场景 | 影响 |
|---|---|
| 源码 2KB、同页 20 实例、1s 刷新 | 无感 |
| 源码 20KB、同页 50 实例、200ms 刷新 | 明显掉帧 |
| 源码 100KB+ | 别这么干 |

优化：
- 精简源码（删编辑器导出的元数据、注释、无用 `<defs>`）；
- 坐标保留 1~2 位小数；
- 100ms 级高频变量不要配复杂 SVG；
- 装饰外壳尽量用少量路径表达。

### 2. 安全（清洗两次）

入库前 `SvgSanitizer.Sanitize` + 渲染前 `sanitizeSvg` 双保险：

- 移除 `<script>`、`<foreignObject>`、`on*` 事件；
- `href`/`xlink:href`/`src` 仅放行 `#锚点` / `data:image/...` / `/站内相对路径`；
- CSS `url(...)` 同白名单；
- **不放行 `http(s)://`** —— 外链图片只能 base64 内嵌（注意 256KB 总长）或上传后用 `/` 路径；
- 超过 256KB 截断。

> `<animate>` 本身允许，可做流向动画；`<animate attributeName="href">` 引外链是已知边界（风险低，留意）。
> `IconKey` 里的 SVG **不**清洗，写图标自觉不放脚本。

### 3. 多实例 id 冲突（重点）

`v-html` 内联进 DOM，同页两个实例会重复 `id`，浏览器「取第一个」→ 渐变/滤镜串台。
**规避**：① 不用 id（实色矩形叠加近似渐变）；② 极特殊命名 + 文档注明「同页建议放一个」；
③ 需要真多实例渐变 → 走 builtin 轨写 SFC（`useId()` 生成唯一 id）。

## 四、调试技巧

1. **先看预览，再上线**：管理页「实时预览」用的是固定示例上下文（02 §七），专治「语法错」「占位符残留」。
2. **占位符拼错会立刻可见**：原样输出 `{xxx}` 就是线索——比静默失败友好。
3. **疑似解析失败**：把 `DefaultPropsJson` / `PropSchemaJson` 贴到任意 JSON 校验器，确认结构合法。
4. **老组件行为异常**：回忆快照语义（§一通用第 5 条）——可能它快照里已有旧值，改模板默认值不生效。
5. **批量覆盖**：`import-bundle` 后端固定走 `rename`；要真覆盖请用管理页逐条 `import` 选 `overwrite`。
