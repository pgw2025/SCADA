## Phase 1 — 数据层（实体 + DbContext + 迁移）

**P1-S1 新增 `ScadaPageFolder` 实体**
- 涉及文件：新建 `Server/ScadaServer.Domain/Entities/ScadaPageFolder.cs`
- 具体任务：定义字段 `Id/ProjectId/Project/ParentFolderId/Parent/Children/Pages/Platform/Name/SortOrder/CreatedAt`，标注 `[Table("ScadaPageFolders")]`、`[Key]`、`[DatabaseGenerated(Identity)]`；`Platform` 与 `Name` 加 `[MaxLength]`（16/100）。
- 验证：实体可编译，字段与 `02-详细设计 §1.1` 一致。

**P1-S2 给 `ScadaPage` 增加 `FolderId` / `SortOrder`**
- 涉及文件：`Server/ScadaServer.Domain/Entities/ScadaPage.cs`
- 具体任务：加 `public int? FolderId { get; set; }` 与 `public int SortOrder { get; set; }`（附注释说明 FK/默认值语义）。
- 验证：无编译错误；不影响既有字段。

**P1-S3 在 `ScadaDbContext` 注册 DbSet 与配置**
- 涉及文件：`Server/ScadaServer.Infrastructure/Persistence/ScadaDbContext.cs`
- 具体任务：`DbSet<ScadaPageFolder>`；`OnModelCreating` 完成——文件夹表名/列限长/默认值、自引用 FK(`Restrict`)+`ix_scadepagefolders_parent`、`ix_scadepagefolders_project_platform`；`ScadaPage.FolderId` FK(`Restrict`)+`ix_scadepages_folderid`；`ScadaPage.SortOrder` `HasDefaultValue(0)`。
- 验证：`dotnet build` 通过；`DbContext` 无重复配置。

**P1-S4 生成 EF 迁移（含存量 SortOrder 回填）**
- 涉及文件：`Server/ScadaServer.Infrastructure/Migrations/*`（自动生成 + 手写回填）
- 具体任务：`AddPageFolder` 迁移建表 + 加列；在 `Up()` 中用 SQL 对 `ScadaPages` 按 `(ProjectId, Platform) ORDER BY Id` 回填递增 `SortOrder`（MySQL 8 可用 `ROW_NUMBER()`；低版本备选应用层一次性脚本）。
- 验证：`dotnet ef migrations script` 预览正确；回填后顺序与现状一致；无数据丢失。

**P1-S5 编译验证**
- 具体任务：`dotnet build`（Server）。
- 验证：0 error；快照文件 `ScadaDbContextModelSnapshot` 正常更新。

**P3-S6 整树/删除/导入接入 folders**
