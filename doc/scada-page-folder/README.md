# 画面列表文件夹化改造（scada-page-folder）

给组态设计页面（`ScadaTopologyView.vue`）的「画面列表」增加文件夹分类管理，把多个画面放入文件夹统一组织，支持文件夹嵌套、拖拽排序、折叠展开。**本目录仅存放设计与实施文档，不含源码改动。**

## 修订说明

本方案是在上一版（原存于 `docs/scada-page-folder`，已删除）基础上，经代码级核对后修订而成。修订解决了上一版的 4 个 P0 缺陷（Popup 口径矛盾、整树 DTO 缺 folders、文件夹双轨持久化缺失、同父级排序语义未定义），并补齐了导出/导入、存量排序回填、命名唯一性、级联删除边界等细节。

## 最终选型（评审结论）

| 决策点 | 结论 |
|---|---|
| 数据模型 | **方案 A：独立文件夹实体** `ScadaPageFolder` 表 + `ScadaPage` 增加 `FolderId`/`SortOrder` |
| 文件夹适用范围 | **仅 Desktop（桌面端）/ Mobile（移动端）**；Popup 弹窗画面不建文件夹、保持单层平铺 |
| 删除文件夹语义 | **默认 reparent（内容上提），cascade 为可选参数** |
| 同父级排序 | **文件夹与画面两套独立 SortOrder，文件夹段恒在上**，不做混排 |
| 前端树 | **手写递归组件 + 原生 HTML5 拖拽**，零新依赖 |
| 前端 id | 文件夹沿用 **uid(string) ↔ serverId(int) 双轨**；页面/文件夹的 `folderId`/`parentFolderId` 前端存 uid，后端存 int FK |

## 核心要点

- 树 = **Platform（桌面端/移动端）→ 文件夹（可嵌套）→ 画面**；Prompt 弹窗画面不纳入。
- 存量画面 `FolderId=NULL` 自动落各端根级，`SortOrder` 按当前查询顺序回填，打开旧工程零顺序漂移。
- 现有画面操作（选中/改名/复制/导出/设首页/删除）、首页唯一性、组件绑定、剪贴板**均不感知文件夹**。
- 导出/导入迁移文件不含文件夹信息，导入画面一律落目标工程根级。
- 文件夹是纯编辑器组织手段，不改动运行时导航与运行逻辑。
