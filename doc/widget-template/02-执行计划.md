- 单测（若项目有测试工程则加，无则用控制台自验脚本验证 6 个用例：script 注入 / onclick 注入 / 外链 href / 多行 href 绕过 / style url() / data:image 通过）。

- `ExportAsync`：读取模板包装为导出 DTO。

- GET {id}/export：返回 `application/json` 附件下载；

### 步骤 1.8 种子数据
