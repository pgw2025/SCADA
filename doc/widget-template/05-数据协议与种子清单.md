## 1. 导入 / 导出文件格式

### 1.1 单模板导出（`{templateKey}.widget.json`）

```json
{
  "format": "scada-widget-template",
  "version": 1,
  "template": {
    "id": 0,
    "templateKey": "my-pump",
    "renderType": "my-pump",
    "name": "定制泵",
    "category": "equipment",
    "description": "客户定制版离心泵",
    "defaultWidth": 100,
    "defaultHeight": 120,
    "iconKind": "svg",
    "iconKey": "<svg>…小图标…</svg>",
    "iconColor": "",
    "renderKind": "svg",
    "svgTemplate": "<svg width=\"100%\" height=\"100%\" viewBox=\"0 0 100 120\">…</svg>",
    "defaultPropsJson": "{\"activeColor\":\"#10b981\",\"inactiveColor\":\"#94a3b8\",\"unit\":\"MPa\",\"thresholdMin\":null,\"thresholdMax\":null}",
    "propSchemaJson": "[{\"key\":\"unit\",\"label\":\"单位\",\"type\":\"text\",\"group\":\"外观\"}]",
    "isSystem": false,
    "sortOrder": 99
  }
}
```

### 1.2 批量导出（`widget-templates-{时间戳}.widget.json`）

```json
{
  "format": "scada-widget-template",
  "version": 1,
  "templates": [ { "…同上 template 对象…" }, { "…" } ]
}
```

### 1.3 导入交互协议

- 前端读文件后兼容两种形态：`template`（单）或 `templates`（数组）；
- 每条冲突项由用户选择：**覆盖**（保留 IsSystem，走 Update）／**重命名导入**（后端 8 位短随机后缀，返回 `newKey`）／**跳过**；
- 后端响应（单条）：`{ ok: true, id: 123, mode: "overwrite" | "create" | "renamed", newKey: "my-pump-a1b2c3d4" }`；
- 入库前：SVG 源码与 svg 图标均过 `SvgSanitizer`；两个 JSON 字段过 parse 校验。

### 1.4 格式演进约定

- `version` 目前 1；未来不兼容变更递增版本号并在导入端做兼容分支；
- 未知字段忽略（向前兼容）；`isSystem` 导入时以库内现值/规则为准，不信任文件值。

## 2. SVG 模板占位符规范（P4）

| 占位符 | 类型 | 来源 | 示例 |
|---|---|---|---|
| `{value}` | number/boolean | 绑定变量原始值 | `12.5` / `true` |
| `{numValue}` | number | 布尔归一为 100/0 | `75` |
| `{boolValue}` | boolean | 布尔化 | `true` |
| `{normalizedPercent}` | number | 量程归一化 0~100（min/max） | `63.5` |
| `{state}` | string | onText/offText 文案 | `运行` / `停止` |
| `{unit}` | string | 单位 | `℃` |
| `{label}` | string | 组件标签 | `1#锅炉` |
| `{activeColor}` | string | 激活色 | `#10b981` |
| `{inactiveColor}` | string | 待机色 | `#94a3b8` |
| `{alertColor}` | string | 告警色（超阈值红/黄，回落 activeColor） | `#ef4444` |
| `{thresholdMin}` / `{thresholdMax}` | number/null | 阈值 | `10` / `null` |
| `{fontSize}` | number | 字号 | `12` |
| `{quality}` | string | 变量质量 | `Good` |

- 未识别占位符**原样保留**（渲染后可直接看到拼写错误）；
- 占位符可出现在任何文本节点与属性值中（如 `fill="{activeColor}"`、`height="{normalizedPercent}"`）；
- 模板根节点约定：`<svg width="100%" height="100%" viewBox="…">`，画布内等比缩放；
- SVG 轨为纯展示（无点击写值；控制类需求走 builtin 轨）。

**SVG 默认 props 预填模板**（管理页新建 SVG 模板时注入，审查 B5）：

```json
{
  "activeColor": "#10b981",
  "inactiveColor": "#94a3b8",
  "maxValue": 100,
  "minValue": 0,
  "unit": "",
  "thresholdMin": null,
  "thresholdMax": null,
  "fontSize": 12
}
```

**最小可用示例**（验收用例直接采用）：

```xml
<svg width="100%" height="100%" viewBox="0 0 100 120" xmlns="http://www.w3.org/2000/svg">
  <rect x="20" y="10" width="60" height="100" rx="8" fill="#e2e8f0" stroke="#475569" stroke-width="2"/>
  <rect x="24" y="{110 - 0.8 * normalizedPercent}" width="52" height="{0.8 * normalizedPercent}" fill="{activeColor}"/>
  <text x="50" y="118" font-size="9" text-anchor="middle" fill="#334155">{value}{unit}</text>
</svg>
```

> 注：属性值占位替换是**字符串替换**，不支持表达式（`{110 - 0.8 * …}` 不生效）。上例修正版应改用绑定即值：柱高直接用 `{normalizedPercent}%`（SVG 属性支持百分比）或预先在占位符中提供派生值。**实施时占位符集若不满足需求，扩展 SvgBindingContext 派生字段而不是引入表达式引擎。**

## 4. 模板生命周期规则

### 4.1 画布落布（快照语义，D4）

```
拖拽/点击组件库项
  → payload: { type: def.type, w, h, name, extraProps: def.defaultProps() }
  → HmiComponent.Type = def.type（builtin=renderType；svg=templateKey）
  → PropsJson = extraProps 快照（此后与模板默认值解耦）
```

### 4.2 模板编辑的影响面

| 变更项 | 已放置组件 | 新放置组件 |
|---|---|---|
| 名称/描述/图标/排序/分类 | 不变（仅组件库展示） | 生效 |
| 默认尺寸 | 不变 | 生效 |
| defaultProps | 不变（快照） | 生效 |
| SVG 源码 | **实时生效**（渲染时读取模板） | 生效 |
| 删除模板 | 显示「组件缺失」卡，可选中编辑属性，PropsJson 保留 | 无法放置 |
| 重导入同键模板 | 自动恢复渲染 | 可放置 |

### 4.3 两级匹配决策表

| 画布组件 type | 匹配路径 | 结果 |
|---|---|---|
| `boiler`（存量/新放置） | store key=`boiler` 精确 | boiler 模板 |
| `title-header`（存量页面） | key 未命中 → renderType 泛化 | title-header-tech-desktop（sortOrder 最小者） |
| `my-pump`（svg 新放置） | key 精确 | my-pump（svg 轨） |
| `button`（legacy 存量） | 未命中模板 → builtinRenderers 直取 | ButtonWidget 渲染，属性面板走既有 v-if 分支 |
| 未知 `xyz` | 全未命中 | 组件缺失卡 |

### 4.4 快照升级（登记为后续增强，不在本期）

「将模板默认值应用到选中组件」按钮——把 defaultProps 合并进已放置组件（用户确认后覆盖）。本期不做，避免误覆盖已调参的实例。
