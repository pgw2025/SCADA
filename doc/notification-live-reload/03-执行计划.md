## 里程碑与依赖

```
阶段一（步骤1–4）──┐
                    ├── 阶段二（步骤5–6）── 阶段三（步骤7）── 阶段四（步骤8）── 阶段五（步骤9–11）
阶段一四步内部可并行 ┘
```

- 阶段一四步互相独立，可并行/流水线；阶段二依赖阶段一（sender 已具备动态 `Enabled`）。
- 阶段三、四在阶段二之后均可独立，但由于都涉及 `IOptionsMonitor` 签名，建议按顺序推进以确保每次编译状态清晰。
