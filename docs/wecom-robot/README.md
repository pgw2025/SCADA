## 一句话结论

企业微信群机器人（webhook 型）与钉钉群机器人几乎同构，注册为**第 4 个渠道**、实现 `IExternalMessageSender` 接口即可。限流、重试、扇出、投递记录、定向重试等治理能力零改动自动继承。

## 命名约定（全链路必须一致）

- `Sender.Name = "WeCom"`
- 渠道 ID（前端/投递记录） = `weCom`（大小写不敏感匹配 `WeCom`，保证重试链路可用）
