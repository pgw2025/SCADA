## 3. 回滚预案

| 场景 | 回滚方式 |
|---|---|
| P1 后端异常 | `dotnet ef database update` 回退迁移（Down）或直接删表 `HmiWidgetTemplates`；前端未切换数据源，零影响 |
| P2 前端异常 | revert 转发层 commit → widgetRegistry 恢复静态实现（接口未变，依赖文件零改动） |
| P3 管理页异常 | revert 路由/页面 commit；模板表数据保留无副作用 |
| P4 SVG 轨异常 | renderComponent 中移除 svg 分支即回退到纯 builtin；已有 svg 模板在库中无害（不被渲染） |
| 全量回退 | 依次 revert P4→P3→P2 commit；数据库表可保留（无外部依赖）或执行 Down 迁移 |

**数据安全线**：`HmiComponents` 表（画布实例）全程零 schema 变更、零数据迁移——任何阶段回滚都不触碰既有组态页面数据。
