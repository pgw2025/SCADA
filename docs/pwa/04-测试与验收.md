# 04 - 测试与验收

> 与 [03-执行计划.md](03-执行计划.md) 各步骤的验收标准配套：本文档提供可执行的测试用例集、安全专项、兼容性矩阵、回归清单与运维观察项。

## 1. 测试环境与工具

| 项 | 要求 |
|---|---|
| 后端 | 本地 `dotnet run`（:5555），或部署环境 |
| 前端 | `npm run dev`（:3333，SW 经 devOptions 生效）；关键节点用 `npm run build` + HTTPS 预览（`vite preview` 不支持 SW 更新语义时用 nginx 本地起） |
| 浏览器 | Chrome（主）、Edge、Firefox、Safari/iOS 真机（推送必测） |
| 工具 | DevTools（Application: Service Workers/Cache Storage/IndexedDB/Push 模拟、Network 离线/Slow 3G）、Lighthouse、`web-push` 命令行（跨栈验证 payload）、后端测试推送接口（`POST /api/push/test`） |
| 测试账号 | admin（管理员）、op1（Operator，已被授权至少一个组态工程）、op2（无授权，验证空态） |

## 3. 跨账号数据安全专项（最高优先级）

> 背景：SW/IndexedDB 引入新的客户端持久化面，必须验证不重蹈项目授权功能曾出现的「前端缓存绕过」问题。公用一体机（kiosk）是主场景。

| # | 场景 | 操作 | 期望（全部满足才算过） |
|---|---|---|---|
| S1 | 登出后换号离线 | admin 登录浏览（设备/报警/组态工程）→登出→断网→op1 登录 | ① `api-runtime` 已清（登出瞬间）② op1 看到的组态工程列表为其授权集（或空）③ admin 视角数据无处可见 ④ IndexedDB 快照已清 |
| S2 | 直接换号（不经登出） | admin 会话→覆盖登录 op1 | 同 S1 四项（登录路径触发清理） |
| S3 | 401 强登出换号 | 篡改 admin token 触发 401→登出态→op1 登录→断网 | 同 S1 |
| S4 | 防线三兜底（极端） | 模拟 SW 消息丢失（登出瞬间断网后立即操作）→op1 登录 | op1 读不到 admin 快照（userId 前缀命名空间隔离） |
| S5 | Auth 缓存复活攻击 | admin 登录→token 被服务端吊销→断网→刷新 | `/api/Auth/me` 无缓存 → 不会离线"复活"已吊销会话 |
| S6 | 推送不越权 | op1 收到的推送正文 | 仅含报警事件摘要（所有角色可见的报警事实），不含 admin 专属管理数据 |
| S7 | 订阅换绑不串号 | admin 订阅→登出→op1 登录→触发报警 | 通知落地 op1 角色 URL；admin 不再收该浏览器通知（订阅已换绑） |
| S8 | localStorage token 与 SW 行为 | 登出后检查 | token 清除（既有行为不变）；SW 缓存/快照清除；推送订阅保留（设计如此，S7 已验证换号不串） |

## 4. 兼容性矩阵

| 平台 | 安装 | 离线壳 | Web Push | 备注 |
|---|---|---|---|---|
| Chrome/Edge 桌面（新版本） | ✅ | ✅ | ✅ | 主力平台 |
| Firefox 桌面 | ✅（安装支持视版本） | ✅ | ✅（Mozilla 推送服务） | 步骤 19 验证 |
| Android Chrome | ✅ | ✅ | ✅ | PWA 安装态通知渠道 |
| iOS ≥16.4 Safari | ✅（添加主屏） | ✅ | ✅ **仅已安装的 PWA** | 未安装态无推送；引导文案覆盖 |
| iOS <16.4 | 添加主屏可用 | ✅ | ❌ | 降级：仅站内通知 |
| 企业内网老浏览器 | 视情况 | 不支持 SW 则整体降级为现状 SPA | ❌ | 核心功能不受影响（PWA 全部为渐进增强） |

**降级原则**：所有 PWA 能力均为渐进增强——SW/manifest/推送任一不可用时，应用回退为现状纯 SPA 行为，核心功能（登录/管理/组态运行/实时数据）不依赖 PWA 层。

## 6. 运维监控项与红线

| 项 | 建议 |
|---|---|
| 推送成功率 | 定期统计 `PushSubscription.LastErrorCode` 分布与 `LastPushAtUtc` 停滞（>7 天未推送且 Enabled 订阅数异常 → 排查） |
| 订阅数趋势 | 用户增长/流失观测（登出不退订，订阅数只增；410 清理是主要回收路径） |
| SW 更新率 | 版本发布后旧版本滞留（可通过 `GET_VERSION` 探针或后续埋点，暂不强制） |
| VAPID 红线 | **轮换私钥=全部订阅失效**（需公告全员重新开启推送）；单实例持有；私钥不入库不入前端；备份私钥至密钥管理位置 |
| nginx 红线 | `/sw.js` 必须永远 `no-cache`（被 CDN/HTTP 缓存卡住=发版不生效）；manifest Content-Type 正确 |
| 存储压力 | IndexedDB 快照量级随设备×变量增长，超预期启动 TTL/上限（E8 结论） |

## 7. 已知限制（对用户透明化）

1. 离线数据是**最近快照**，非实时值——横幅时间戳持续可见。
2. iOS 推送需先安装到主屏（iOS 16.4+）。
3. 推送级别默认 ≥Error（防噪音），低级别报警请站内查看。
4. 纯订阅设备的高频更新在离线快照中以最后落盘一拍为准（节流粒度 10s）。
5. 换浏览器/换设备需重新开启推送（订阅绑定浏览器）。
