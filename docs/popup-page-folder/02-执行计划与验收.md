## 2. 验收用例清单

| # | 用例 | 预期 |
|---|---|---|
| 1 | 弹窗分组头部点 FolderPlus 建根级文件夹；文件夹行内 FolderPlus 建子夹 | 两级文件夹创建成功，命名防重生效（同层级同名被拒） |

## 3. 回归风险与防御

| 风险 | 场景 | 防御 |
|---|---|---|
| `fromFolderDto` 漏改（P0-④） | 刷新后 Popup 文件夹显示到桌面端树、弹窗树消失 | 验收用例 8 显式覆盖 |
| `NormalizePlatform` 漏改（P0-①） | Popup reorder 被静默归一化成 Desktop → 400 "排序项与目标层级/端不一致" | 验收用例 4/6 显式覆盖 |
| 文件夹 serverId 未就绪即 reorder | 新建夹后立刻拖入弹窗 → 400（既有时序坑，`feat/scada-page-folder` 已修） | `ensureParentReady` 已保证先落库；用例 3+4 连续操作验证 |
| `GetTreeAsync` folders 重复追加 | 刷新后文件夹 ×N 显示（既有坑已修，勿回退） | 用例 8 |
| `RenormalizeOrderAsync` 全库重编号 | 根级删除夹时其他工程/端 SortOrder 被重写（写放大） | 阶段 4.1 修复；不修则表现为潜在性能/一致性隐患 |
| 运行态误染 | 弹窗被设首页/端切换 | 用例 10 + `setHomePage` 守卫双保险 |

## 4. 已知行为（非缺陷，三端一致，勿单独"修"）

- 复制弹窗的副本落弹窗根级（`handleDuplicatePage` 不复制 folderId/sortOrder）。
- 导出/导入不含文件夹归属信息。
- 新建弹窗（Plus 按钮）落弹窗根级。
- cascade 删除守卫按**工程全量页面**计数（允许删到最后一个弹窗，只要工程还有画面）。
