- **1.1** `types.ts`：`HmiEventActionKind` 追加 `'openPopup'`；`HmiEventAction.params` 追加 `sourceComponentId?` 与 `requireWritePermission?`。
- **1.2** `EventPanel.vue`：
  - `AppWindow` 图标导入；`ACTION_KIND_META` 加 `openPopup: { label:'打开弹窗面板' }`；
  - `addAction` params 初始化加 `openPopup` 分支；

- **1.3** `EventPanel.vue` 模板：`openPopup` 参数编辑区（组件下拉 + 开窗权限 checkbox）；底部提示文案补弹窗说明。
- **1.4** 验证：`npm run build` 通过（`ACTION_KIND_META` 完整性由类型 `Record<HmiEventActionKind,…>` 强制，缺键会编译失败——已通过）。

### 阶段 2：运行时弹窗核心
- **2.1** 新增 `Client/src/utils/componentDeviceRefs.ts`：`collectComponentDeviceRefs` 收集 `bindDeviceId` + props 中 `*DeviceId` 后缀数字字段（正则 `/DeviceId$/i`），Set 返回。
- **2.2** `hmiEventService.ts`：
  - `HmiEventDispatchContext` 追加**可选** `openPopup?: (sourceComponentId: string) => void`（P2：可选成员保证预览宿主不强制）；
  - `runAction` 加 `openPopup` 分支：`requireWritePermission` 前置拦截 → 空 sourceId 跳过 → `ctx.openPopup` 判空降级 `onBlocked('当前宿主不支持弹窗动作')`。
- **2.3** 新增 `Client/src/components/PopupHost.vue`：`fixed inset-0 z-[100]`、复用 `HMIWidget` 渲染 `descriptor`（浅拷贝置 `visible:true/locked:false`、剥离 `layerId`）、标题栏、X/ESC/遮罩关闭、`control-locked=!canControlWrite`。
- **2.4** `ScadaPlayerView.vue`：
  - 弹窗状态区（`activePopupId`/`activePopupComponent`/`openPopup`/`closePopup`）；E1 切页 watch；E2 悬空 toast；E5 幂等；
  - 弹窗设备订阅差集 watch（补订/退订主订阅未覆盖设备）；onUnmounted 兜底退订弹窗设备；
  - `eventCtx` 接 `openPopup`；模板 CanvasPanel 容器外挂 `PopupHost`（SetValueDialog 同级）。
- **数据链路确认**：`VfdMotorPanelWidget.vue` 直接读 `devices` store（`readVar`，逐点 `propOr(xxxDeviceId)` 覆盖）——差集订阅设计正确。

### 阶段 3：预览宿主 + 缺口收口
- **3.1 前置检查**：预览宿主有自建 `boundDeviceIds` + 订阅 watch → 采用完整弹窗集成。

## 5. 待手动复核项（需真实设备/数据库联链）

下列验收清单项属运行交互，需在可用运行环境（真实或模拟设备 + 角色账号）复核：

1. **弹窗开合**：Operator 点击电机 → `vfd-motor-panel` 弹窗出现、标题为组件名；X/ESC/遮罩三方式关闭；重复点击幂等。
2. **权限**：Viewer 可开窗只读（面板按钮置灰）；`requireWritePermission=true` 时 Viewer 开窗被拦截提示；Operator/Admin 可写。
3. **数据实时**：面板绑定设备不在页面其余组件中时，弹窗数值实时刷新（验证差集订阅）。
4. **boundDeviceIds 收口**：画布上 `vfd-motor-panel` 配置跨设备点位绑定后，画布面板数值实时（验收 6.3 修复项）。
5. **边界**：弹窗开启时 nav-menu 切页自动关闭；删除被引用面板后点击给「目标不存在」提示；编辑器预览态（isActiveMode）弹窗同体验。
6. **配置持久化**：openPopup 事件保存/重载回显完整。
7. **回归**：写变量/跳转/脚本/setProp 四类既有动作不回归；SetValueDialog 设值弹窗不受影响；桌面/移动双端布局与无缩放失真。
