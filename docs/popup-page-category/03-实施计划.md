## 关键设计决策（D1–D10）

| # | 决策 | 理由 |
| --- | --- | --- |
| D1 | platform 扩为 `'Desktop' \| 'Mobile' \| 'Popup'` 三值，DB 零迁移 | Platform 为纯 string 列，无枚举转换/CHECK 约束 |
| D2 | openPopup 不新增 kind，以 `params.popupTargetType`（`'component'` 默认 / `'page'`）区分两种形态 | 旧配置零迁移，`?? 'component'` 回退旧行为 |
| D3 | Popup 不参与运行主画面（runtimePages 天然排除）、不设首页 | 只被动调用不落地，`UnsetOtherHomePagesAsync` 按 `(ProjectId,Platform)` 分域无副作用 |
| D4 | 弹窗画面宿主 = ModalShell + 嵌套 CanvasPanel | 复用画布全部能力（组件/图层/背景/适配/缩放/交互），而非自绘容器 |
| D5 | **P1**：弹窗画面事件走"弹窗作用域第二上下文 + 归属路由"，数据事件挂 `useHmiDataEvents` 第二实例 | 主 ctx 的 setProp/openPopup/数据监听均以主画面 components 解析，直接复用会静默失效 |
| D6 | **P2**：SetValueDialog / PopupHost / PopupPageHost 三模态互斥 + 模板层级排序 | 同 z-[100] 且 DOM 顺序不定，会遮蔽/叠加 |
| D7 | **O1**：抽 ModalShell 共用壳；PopupHost 改造时顺带补齐 `requestSetValue` 既有缺陷 | 防两份关闭逻辑漂移；修复组件弹窗内 var-display 设值被静默丢弃 |
| D8 | 设备订阅走差集：弹窗页全部组件聚合 `collectComponentDeviceRefs`，关闭退订"不再被引用"者 | 保证弹窗内实时值；不留订阅残留 |
| D9 | 首版单层弹窗（禁嵌套）、不做 deviceId 参数化（预留 `popupDeviceIds` 字段不消费） | 控制复杂度；参数化与嵌套栈留扩展 |
| D10 | `popupPageComponentValues` 用 `bindDeviceId+bindVariableKey` 严格复合键 | 与主画面 `componentValues`（L151-177）同源逻辑，严禁裸 key |

## 阶段 0：数据层与基础（5 步）

### 0.1 后端 NormalizePlatform 三值白名单

- **任务**：让后端接受并归一化 `'Popup'` 分类。
- **改动文件**：`Server/ScadaServer.Application/Services/ScadaPageAppService.cs`
- **具体内容**：`NormalizePlatform`（L141-143）改为 switch 表达式三值白名单：

```csharp
/// <summary>归一化归属端：Desktop / Mobile / Popup，空/非法值一律回退 Desktop。</summary>
private static string NormalizePlatform(string? platform)
    => platform?.Trim() switch
    {
        "Mobile" => "Mobile",
        "Popup" => "Popup",
        _ => "Desktop",
    };
```

- **验证**：`dotnet build` 通过；启动后用接口 `POST /api/ScadaPage` 传 `Platform: "Popup"` 创建页面，
  `GET` 回读 `platform === 'Popup'`；传 `"popup"`（大小写）经 `Trim()`+switch 归一为 `"Popup"`。
- **注意**：**这是全方案唯一后端业务改动**。`CreateAsync`（L60-82）/`UpdateAsync`（L84-106）均经

```ts
case 'openPopup': {
  if (p.requireWritePermission && !ctx.canControlWrite) {
    ctx.onBlocked?.('当前角色无弹窗操作权限'); return;
  }
  if (p.popupTargetType === 'page') {
    const pageId = p.panelPageId;
    if (!pageId) { ctx.onBlocked?.('未选择弹窗画面'); return; }
    if (!ctx.openPagePopup) { ctx.onBlocked?.('当前宿主不支持弹窗画面动作'); return; }
    ctx.openPagePopup(pageId); return;
  }
  // ★ 原"弹组件"逻辑原样保留（旧行为）
  const sourceId = p.sourceComponentId;
  if (!sourceId) return;
  if (!ctx.openPopup) { ctx.onBlocked?.('当前宿主不支持弹窗动作'); return; }
  ctx.openPopup(sourceId); return;
}
```

- **注意**：`openPagePopup` 声明为**可选**，保证未接入的宿主（若有第三处）TS 编译不炸；旧分支一行不动。
