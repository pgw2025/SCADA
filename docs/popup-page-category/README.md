## 核心结论速览

- **零数据库迁移**：`ScadaPage.Platform` 为纯 string 列，新增 `'Popup'` 值仅改后端
  `NormalizePlatform` 白名单一处业务逻辑。
- **前端最易漏点**：`scadaApi.ts fromPageDto`（L246）现把非 Mobile 归为 Desktop，必须改三值透传，
  否则 Popup 页刷新即变桌面页。
- **P1（架构关键）**：弹窗画面内组件的事件不能复用主画面 `eventCtx`（setProp/openPopup/数据事件
  均以主画面 components 解析）——需弹窗作用域第二上下文 + 归属路由 + `useHmiDataEvents` 第二实例。
- **P2**：SetValueDialog / PopupHost / PopupPageHost 三类模态互斥 + 层级排序，防遮蔽与叠加。
- **兼容**：现有 openPopup（弹组件）行为与已保存配置零影响，新"弹画面"以 `popupTargetType:'page'`
  并行分支共存。
